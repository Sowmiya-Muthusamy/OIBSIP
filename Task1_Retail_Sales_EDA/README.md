# Task 1: Exploratory Data Analysis on Retail Sales

## Project Overview
This project explores a retail sales dataset using Python to understand sales trends and customer purchasing patterns.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Dataset inspection and data quality checks
- Descriptive statistics
- Monthly and quarterly sales trends
- Customer transaction analysis by gender and age group
- Revenue analysis by product category
- Correlation heatmap
- Transaction amount distribution

## Files
- `Task1_Retail_Sales_EDA.ipynb` — notebook containing the analysis and visualizations
- `retail_sales_cleaned.csv` — dataset saved after analysis and feature creation

## Conclusion
The analysis examines retail sales trends, customer transaction patterns, and product category revenue. It also identifies sales fluctuations that may need further investigation.

## How to Run
1. Install Python and Jupyter Notebook.
2. Install the required libraries: `pandas`, `matplotlib`, and `seaborn`.
3. Open the notebook and run the cells in order.
